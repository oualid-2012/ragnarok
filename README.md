## 🎮 Overview

**Ragnarok: The New World** is a single-screen, multi-section web experience crafted with an editorial art-directed design inspired by modern high-end AAA PC MMORPG portals.

### ✨ Key Features
- **In-Place Stage Navigation**: Seamless fluid transitions between 5 interactive sections (`Home`, `Gameplay`, `Heros`, `System Requirements`, `Download`) without page reloads or jarring vertical scroll jumping.
- **Cinematic Hero**: Looping background video, floating 3D game logo, bespoke fantasy typography (`Cinzel Decorative`), and a high-impact golden download call-to-action button with live proof statistics.
- **Interactive Heroes Roster**: 8 iconic MMORPG classes (Swordsman, Mage, Archer, Thief, Acolyte, Merchant, Gunslinger, Druid) with dynamic stat radars, ability tooltips, and high-resolution art showcase.
- **4K Gameplay Media Showcase**: Filterable gallery of official in-game screenshots and trailer spotlight.
- **System Requirements Checker**: Tabbed Minimum vs Recommended desktop PC specification cards.
- **Multilingual Support (i18n)**: Instant localized experience across 5 languages:
  - English (`en`)
  - Français (`fr`)
  - Bahasa Indonesia (`id`)
  - ภาษาไทย (`th`)
  - 简体中文 (`zh-CN`)
- **Official BGM Audio Player**: Interactive theme music controller with persistent mute/unmute state.
- **Steam Outbound Affiliate Tracking**: Built-in conversion attribution for every download CTA.

## 🛠️ Technology Stack

Built strictly adhering to high-performance vanilla web standards:
- **HTML5**: Semantic, accessible markup.
- **CSS3**: Modular tokens, CSS Grid, Flexbox, custom keyframe animations, responsive clamp scaling.
- **Vanilla JavaScript (ES5/ES6)**: Zero runtime frameworks (No React, Vue, Angular, or Tailwind) for instant sub-second load times.

## 🌐 Live GitHub Pages Deployment

To host this repository on **GitHub Pages**:
1. Go to repository **Settings** > **Pages**
2. Under **Build and deployment** > **Branch**, select `main` (or `gh-pages`) and `/ (root)`
3. Click **Save**
4. Your website will be live at:
   `https://oualid-2012.github.io/ragnarok/`
